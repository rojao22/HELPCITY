Comunitários
1. O Problema
Qual problema foi escolhido
Muitas cidades possuem dificuldades no gerenciamento de ocorrências urbanas, como:
● enchentes;
● buracos nas ruas;
● acidentes;
● problemas de iluminação pública;
● alagamentos;
● trânsito;
● descarte irregular de lixo.
Além disso, a população muitas vezes não possui um sistema rápido e organizado para
comunicar esses problemas à prefeitura.
Por que ele é importante
A falta de comunicação eficiente entre população e prefeitura causa:
● demora na resolução de problemas;
● aumento de acidentes;
● insegurança;
● desorganização urbana;
● dificuldade na tomada de decisões públicas.
Quem sofre com esse problema
● moradores da cidade;
● motoristas;
● pedestres;
● comerciantes;
● equipes da prefeitura;
● serviços de emergência.
2. A Solução
Nome da solução
HelpCity
Como o sistema resolve o problema
O sistema cria uma plataforma digital onde cidadãos podem registrar ocorrências urbanas
em tempo real, enquanto a prefeitura acompanha, organiza e gerencia os chamados.
Também existe um sistema de alertas para informar a população sobre riscos e
emergências.
Principais funcionalidades
● Cadastro de ocorrências;
● Sistema de alertas urbanos;
● Gerenciamento administrativo;
● Dashboard moderno;
● Mapa da cidade;
● Organização de chamados;
● Interface responsiva;
● Integração com banco de dados;
● Atualizações em tempo real.
Diferencial da solução
O diferencial do HelpCity é unir:
● gestão urbana;
● comunicação pública;● monitoramento;
● alertas comunitários;
● centralização de informações.
Tudo em uma interface moderna e intuitiva inspirada em sistemas reais de prefeitura
inteligente.

Estrutura do Front-end
O sistema possui as seguintes páginas:
● index.html → Página inicial;
● ocorrencias.html → Registro de ocorrências;
● alertas.html → Sistema de alertas;
● gerenciamento.html → Painel administrativo;

O back-end realiza:

● armazenamento;
● integração entre páginas;
● gerenciamento das ocorrências.

9. Instruções para Execução Local
Instalar dependências
npm install
Instalar JSON Server
npm install -g json-server
Rodar banco de dados
json-server --watch db.json
Abrir o projeto
Abrir o arquivo:
index.html
Ou utilizar a extensão Live Server no VSCode.
